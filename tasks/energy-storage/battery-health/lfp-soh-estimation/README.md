# References

Wheeler, W., Bultel, Y., Venet, P., & Sari, A. (2025). An ageing study of twenty 18650 lithium-ion Graphite/LFP cells in first and second life use. *Scientific Data, 12*, 392. https://doi.org/10.1038/s41597-025-04712-7

**How it informs the task:** This paper documents the real Graphite/LFP ageing experiment, cell chemistry, test conditions, periodic characterization protocol and intended use of the data for battery diagnosis and prognosis. It provides the scientific basis for using the RPT measurements and for treating cell ageing and second-life behaviour as a realistic research problem.

Wheeler, W., Bultel, Y., Venet, P., & Sari, A. (2025). *Aging study on twenty A123 18650 Graphite/LFP 1.1 Ah cells* [Data set]. Recherche Data Gouv. https://doi.org/10.57745/OLBXKT

**How it informs the task:** This is the source data record used to construct the benchmark environment. The task uses a defined subset of the published experimental measurements and preserves the raw diagnostic structure needed for protocol interpretation and feature extraction.

Lundberg, S. M., & Lee, S.-I. (2017). A unified approach to interpreting model predictions. *Advances in Neural Information Processing Systems, 30*.

**How it informs the task:** This work provides the SHAP framework used by the reference solution to summarize the contribution of selected diagnostic features to model predictions.

Pedregosa, F., Varoquaux, G., Gramfort, A., Michel, V., Thirion, B., Grisel, O., Blondel, M., Prettenhofer, P., Weiss, R., Dubourg, V., Vanderplas, J., Passos, A., Cournapeau, D., Brucher, M., Perrot, M., & Duchesnay, E. (2011). Scikit-learn: Machine learning in Python. *Journal of Machine Learning Research, 12*, 2825–2830.

**How it informs the task:** Scikit-learn provides the grouped cross-validation, feature-selection interfaces, regression estimators and performance metrics used by the reference implementation.
